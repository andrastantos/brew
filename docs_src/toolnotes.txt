HOW TO BUILD THE TOOLSET?
=========================

Prerequisites:

  sudo apt install \
    texinfo \
    bison \
    yacc \
    flex \
    dejagnu \
    autogen \
    libmpc-dev \
    libmpfr-dev \
    libisl-dev

TARGET=brew-linux-newlib
or
TARGET=brew-none-elf
PREFIX=~/brew-toolset
export PATH=$PATH:$PREFIX/bin
# for cygwin:
export BREW_BLD_EXTRA="--build=x86_64-w64-cygwin --host=x86_64-w64-cygwin"
# for mingw:
export BREW_BLD_EXTRA="--build=x86_64-w64-mingw32 --host=x86_64-w64-mingw32"

1. binutils:
  mkdir brew-binutils-build
  cd brew-binutils-build
  ../brew-binutils-gdb/configure --target=$TARGET --prefix=$PREFIX --no-recursion --enable-sim-profile=yes $BREW_BLD_EXTRA
  if you want easy debugging instead of optimizations
  ../brew-binutils-gdb/configure --target=$TARGET --prefix=$PREFIX --no-recursion --enable-sim-hardware --enable-sim-profile=yes $BREW_BLD_EXTRA CFLAGS='-g -O0' CXXFLAGS='-g -O0'
  make
  make install
2. gcc + newlib (in-tree, single pass):
  newlib and libgloss are built as part of the GCC build (a 'combined tree'). This
  needs one-time symlinks in the GCC source tree; they are listed in
  brew-gcc/.git/info/exclude so git ignores them:
    ln -s ../brew-newlib/newlib   brew-gcc/newlib
    ln -s ../brew-newlib/libgloss brew-gcc/libgloss
    echo /newlib >> brew-gcc/.git/info/exclude
    echo /libgloss >> brew-gcc/.git/info/exclude
  mkdir brew-gcc-build
  cd brew-gcc-build
  ../brew-gcc/configure --target=$TARGET --prefix=$PREFIX --enable-languages="c,c++" --with-newlib --disable-shared --disable-libssp --disable-threads --disable-libgomp --disable-libatomic --disable-werror $BREW_BLD_EXTRA
  for linux: add --enable-newlib-multithread (it is passed on to newlib)
  make
  make install

  binutils must be installed (and in PATH) before this step. The old 3-step flow
  (gcc phase 1, separate newlib build, gcc phase 2) is no longer needed.
  To rebuild only newlib after changing it: make all-target-newlib all-target-libgloss && make install
  in brew-gcc-build.

Building on a modern host (GCC >= 15):
  export CFLAGS="-O2 -g -std=gnu17" CFLAGS_FOR_BUILD="-O2 -g -std=gnu17"
  (C23 default breaks K&R-style code in readline) and add --disable-werror to the binutils
  configure line as well (new warnings in bfd). configure caches flags; use a fresh build dir
  after changing them.

All of the above (including the newlib symlinks and the host-compiler flags) is automated
by build-toolchain.sh in the root of the brew repo. It expects brew-binutils-gdb, brew-gcc
and brew-newlib to be checked out next to brew, and creates the build directories and a
build-logs/ directory there as well:
  brew/build-toolchain.sh                  # binutils, then gcc+newlib
  brew/build-toolchain.sh gcc              # just one step (reuses the existing build dir)
  CLEAN=1 brew/build-toolchain.sh          # reconfigure from scratch
  PREFIX=... TARGET=... override the defaults (~/brew-toolset, brew-none-elf).

To run the gcc tests:

    make check RUNTESTFLAGS="--target_board=brew-sim"

To run a single test, add the folowing to RUNTESTFLAGS:
    --tool <gcc or g++> <exp file name>=<test name>
  for instance:
    --tool gcc dg.exp=20000108-1.c

But for that we need to copy brew-sim.exp to /usr/share/dejagnu/baseboards

HOW TO FORK REPOS?
==================

If a repo is not on github:

git clone <original>
git remote rename origin upstream
git remote add origin <github fork>
git push origin --all



HOW TO CROSS COMPILE?
=====================

HOST=brew-none-elf
PREFIX=$PWD/result
PATH=$PATH:$PREFIX/bin
mkdir build
mkdir result
cd build
../<package>/configure --host=$HOST --prefix=$PREFIX
